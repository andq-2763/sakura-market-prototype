# 03_Design (UI/UX) — Wireframe

> Thư mục `02_Spec&Design/03_Design (UI/UX)` của spec-standard (không có template).

| File | Nội dung |
|---|---|
| `wireframes/wireframes.html` | Nguồn wireframe (HTML/CSS, 1 file, mở bằng trình duyệt). Sửa ở đây rồi xuất lại PNG |
| `wireframes/SCR-*.png` | Ảnh xuất (2x) dán vào Screen spec theo yêu cầu template "dán ảnh từ công cụ thiết kế" |

Quy ước: đen trắng, low-fidelity về màu nhưng **đầy đủ trường, nhãn tiếng Nhật thật, dữ liệu mẫu nhất quán với seed LAB-2** (N03 hết hạn, B02 tạm dừng, N05 sắp hết hạn …) và **1 trạng thái quan trọng mỗi màn hình** (lỗi tư cách, offline, maker≠checker, chặn khóa ngày, giới hạn 4 lần/năm). Huy hiệu đen `A-1` … trùng cột ID của bảng View trong spec. PC 1280×800, tablet 1024×768.

Khác LAB-2 (mock nhanh): LAB-2 là màn hình chạy thật nhưng bố cục tối giản; wireframe LAB-4 thêm các phần mà prototype chưa có (vùng kiểm tra trước, phím tắt, offline, preview 赤黒, lý do 0 円, bộ đếm 4 lần/năm, trạng thái tư cách đầy đủ).
