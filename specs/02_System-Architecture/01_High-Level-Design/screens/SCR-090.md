## Description

照合事務局 tải file từ hệ thống kế toán (ADR-009) và nhập vào hệ thống. **Kiểm tra toàn bộ file trước, có 1 dòng lỗi thì không nhận dòng nào** (all-or-nothing) và hiện lỗi theo dòng. Sau khi nhập, cho sửa tay từng dòng có lý do (Q-09 「手入力補正あり」). Số phải trả (請求額) lấy từ file này — giả định A4-04, chờ Q-30.
